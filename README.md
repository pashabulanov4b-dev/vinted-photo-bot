# 🛍️ Vinted Photo Bot

Telegram-бот: надсилаєш фото речі → безкоштовний AI (Groq) розпізнає, що це → бот шукає схожі оголошення на Vinted і показує фото, ціни, розміри та посилання.

## Як працює
1. Користувач надсилає фото (можна з підписом: «розмір M», «до 30€», «тільки чорні») і обирає: **🔎 Схожа річ** або **👗 Весь аутфіт**.
2. AI визначає річ, бренд і складає 3 пошукові запити (від точного до загального) — тільки німецькою та англійською.
3. Бот шукає на Vinted і перевіряє кожне оголошення:
   - **фільтр за назвою**: відкидає схожі, але інші речі (напр. вельвет замість клітинки, смужка замість клітинки);
   - **візуальна перевірка**: AI порівнює фото оголошень з твоїм фото і лишає тільки ті, що справді схожі (оцінка ≥ 6/10).
4. Надсилає до 6 найкращих оголошень альбомом + список з посиланнями.
5. Під результатами — кнопки з пошуком на Vinted для кожного запиту.
6. Якщо Vinted заблокує запит із сервера — бот все одно дає кнопки з готовим пошуком.

### 👗 Аутфіти
- **Одне фото → «Весь аутфіт»**: AI розбирає образ на речі (куртка, джинси, взуття, сумка…), шукає кожну окремо і показує по 3 варіанти + загальну ціну образу.
- Підпис зі словом «аутфіт» / «образ» / «outfit» — одразу шукає весь образ, без кнопок.
- **Альбом з кількох фото** (до 3 аналізуються) — збирає з них один аутфіт. Для цього потрібне безкоштовне сховище Upstash Redis (див. нижче). Без нього кожне фото альбому обробляється окремо.

Також працює текстовий пошук будь-якою мовою: «білі найки до 40€» → бот сам перекладе на німецьку/англійську.

## Запуск (GitHub + Vercel)
1. **Бот:** у @BotFather → `/newbot` → скопіюй токен.
2. **Безкоштовний ключ Groq:** console.groq.com → API Keys → Create API Key (картка не потрібна).
3. Завантаж папку в новий репозиторій на GitHub.
4. Vercel → Add New Project → обери репозиторій → Deploy.
5. Vercel → Settings → Environment Variables (див. `.env.example`):
   - `TELEGRAM_BOT_TOKEN`
   - `GROQ_API_KEY`
   - `WEBHOOK_SECRET` — будь-який довгий випадковий рядок
   - `VINTED_DOMAIN` — `www.vinted.de` (або `www.vinted.pl`, `www.vinted.fr`…)
   
   Після додавання — Redeploy.
6. Підключи webhook (один раз, з комп’ютера з Node 20+):
   ```bash
   TELEGRAM_BOT_TOKEN=... WEBHOOK_SECRET=... node scripts/set-webhook.js https://твій-проєкт.vercel.app
   ```
7. Відкрий бота в Telegram → `/start` → надішли фото.
8. *(Для альбомів)* Vercel → проєкт → **Storage** → **Create** → **Upstash for Redis** (Free) → підключи до проєкту → Redeploy. Змінні `KV_REST_API_URL` і `KV_REST_API_TOKEN` додадуться самі.

## Важливо
- У Vinted немає офіційного API: бот використовує внутрішній пошуковий endpoint сайту. Він може змінитись або блокувати сервери Vercel — тоді спрацює запасний варіант із кнопками. Для особистого використання це ок, але масове скрапінг-навантаження порушує правила Vinted.
- Модель за замовчуванням — `qwen/qwen3.8-27b` на Groq (безкоштовний тариф має ліміти запитів, для особистого бота їх вистачає). Якщо Groq змінить модель — постав нову через змінну `GROQ_MODEL` (список: console.groq.com/docs/vision).
